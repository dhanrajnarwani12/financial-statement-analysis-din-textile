# Financial Statement Analysis — Din Textile Mills

## Overview
This project analyzes the financial performance of Din Textile Mills Ltd using financial statement analysis techniques.

The analysis evaluates the company's profitability, liquidity, efficiency, and financial stability using different accounting and analytical methods.

## Analysis Included
- Ratio Analysis
- Horizontal Analysis
- Vertical Analysis
- Profitability Analysis
- Liquidity Analysis
- Shareholding Analysis

## Financial Metrics
- Current Ratio
- Debt Ratio
- Earnings Per Share (EPS)
- Return on Assets (ROA)
- Return on Equity (ROE)
- Operating Margin

## Files Included
- Full Financial Analysis Report
- Charts and Tables
- Financial Statements Analysis

## Tools Used
- Financial Reporting
- Business Analysis
- Excel
- Accounting Principles
- Financial Ratio Techniques

## Key Learning
Understanding corporate financial health using analytical financial techniques and evaluating company performance through financial statement interpretation.
